# The Server Commander | AWS EC2 & Linux

## Project Overview

**The Server Commander** is a hands-on cloud computing project completed as part of my Cloud Computing Internship at **DecodeLabs**.

The project focuses on launching a Linux virtual server on Amazon EC2, accessing it through AWS EC2 Instance Connect, configuring network access, and preparing it to host a custom webpage using the Apache web server.

## Technologies Used

- **Cloud Platform:** Amazon Web Services (AWS)
- **Compute Service:** Amazon EC2
- **Operating System:** Ubuntu Linux
- **Remote Access:** EC2 Instance Connect / SSH
- **Web Server:** Apache HTTP Server
- **Networking:** AWS Security Groups

## Project Objectives

- Launch and configure a Linux EC2 instance.
- Understand instance states and system health checks.
- Configure inbound network rules using security groups.
- Establish access to an Ubuntu server.
- Install and configure the Apache web server.
- Host a custom webpage accessible through a browser.

## Implementation Progress
- Launched an EC2 instance.
- Verified that the instance was running and passed its status checks.
- Opened an Ubuntu terminal using EC2 Instance Connect.
- Installed and verified Apache HTTP Server.
- Created a custom DecodeLabs welcome webpage.
- Verified the webpage through the instance's public IP address.
